## Preferencias del usuario

- Specs con el formato y nivel de detalle de `specs/07`, `08`, `09`.
- 3 juegos por tema, cada uno en su carpeta; mínimo 2 specs completas.
- El usuario puede exigir que uno de los 3 juegos sea una sugerencia `sugerido` concreta del registro (p. ej. `escalada` en 2026-11-24): respetar id/título/categoría/color y hacerla la spec más detallada.
